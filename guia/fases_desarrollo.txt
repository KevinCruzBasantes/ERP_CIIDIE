CONTEXTO RÁPIDO
---------------
Este es un ERP web para un laboratorio universitario de máquinas
de diseño industrial (optimill, cortadoras, etc.). Incorpora TPM
(Mantenimiento Productivo Total). Stack: Django + MariaDB +
servidor HP ProLiant DL285 G1. El documento de requerimientos
completo está en requerimientos.txt.

PASO 2 — Crear el proyecto Django (PENDIENTE)
-----------------------------------------------
Objetivo: Estructura base del proyecto con todas las apps.

Comandos a ejecutar:
  mkdir /var/www/erp_laboratorio && cd /var/www/erp_laboratorio
  python3 -m venv venv
  source venv/bin/activate
  pip install django mysqlclient pillow

  django-admin startproject config .
  python manage.py startapp maquinas
  python manage.py startapp usuarios
  python manage.py startapp mantenimiento
  python manage.py startapp inventario
  python manage.py startapp reservas
  python manage.py startapp reportes
  python manage.py startapp tpm

Estructura de apps:
  maquinas/     → Máquinas y piezas
  usuarios/     → Usuarios, roles, permisos, certificaciones
  mantenimiento/ → Mantenimiento preventivo/correctivo
  inventario/   → Materiales y consumos
  reservas/     → Reservas y órdenes de trabajo
  reportes/     → Dashboard, alertas, exportación Excel
  tpm/          → OEE, inspecciones diarias, incidentes

Preguntar a Claude en el Proyecto:

PASO 4 — Definir los modelos Django (PENDIENTE)
-------------------------------------------------
Objetivo: Crear todos los modelos según el ERD diseñado.
Este es el paso más importante — define toda la base de datos.

Orden de creación de modelos:
  1. usuarios/models.py   → Rol, Permiso, Usuario
  2. maquinas/models.py   → Maquina, Pieza, TransferenciaPieza
  3. mantenimiento/models.py → Mantenimiento
  4. inventario/models.py → Material, ConsumoMaterial
  5. reservas/models.py   → Reserva, OrdenTrabajo
  6. tpm/models.py        → RegistroOEE, CertificacionUsuario,
                            InspeccionDiaria, Incidente

Las 15 tablas del ERD:
  Núcleo (11):
    ROL, PERMISO, USUARIO, MAQUINA, PIEZA,
    TRANSFERENCIA_PIEZA, MANTENIMIENTO, MATERIAL,
    CONSUMO_MATERIAL, RESERVA, ORDEN_TRABAJO
  TPM (4):
    REGISTRO_OEE, CERTIFICACION_USUARIO,
    INSPECCION_DIARIA, INCIDENTE

Comando tras crear los modelos:
  python manage.py makemigrations
  python manage.py migrate

Preguntar a Claude en el Proyecto:
"Escribe todos los modelos Django completos para el ERP del
laboratorio según el ERD y el Paso 4 del documento de fases."


PASO 5 — Panel de administración (PENDIENTE)
----------------------------------------------
Objetivo: Registrar todos los modelos en admin.py para tener
una interfaz funcional desde el día 1.

Por cada modelo, configurar:
  - list_display (columnas visibles en la lista)
  - list_filter (filtros laterales)
  - search_fields (campos de búsqueda)
  - Inlines donde corresponda (ej: piezas dentro de máquina)

Comandos:
  python manage.py createsuperuser
  python manage.py runserver 0.0.0.0:8000

Acceso desde la red del lab: http://IP_SERVIDOR:8000/admin

Preguntar a Claude en el Proyecto:
"Genera el admin.py completo para todas las apps del ERP
del laboratorio con el Paso 5 del documento de fases."


PASO 6 — Desarrollo de módulos (PENDIENTE)
-------------------------------------------
Objetivo: Construir las vistas, formularios y templates de
cada módulo. Orden recomendado:

  Módulo 1: Usuarios y login
    - Login con detección de rol
    - Redirect automático según rol al entrar
    - Decoradores de permiso por vista
    - Cambio de contraseña

  Módulo 2: Máquinas y piezas
    - Listado de máquinas con estado visual
    - Ficha completa de máquina (datos + fotos + manual)
    - Registro de piezas con fotos de ubicación
    - Formulario de transferencia de piezas

  Módulo 3: Mantenimiento
    - Dashboard de estados (próximo / vencido / al día)
    - Formulario de mantenimiento (similar al DANEC)
    - Historial por máquina

  Módulo 4: Reservas y órdenes de trabajo
    - Calendario de reservas por máquina
    - Verificación automática de certificación vigente
    - Formulario de orden de trabajo
    - Registro de tiempos reales

  Módulo 5: Inventario
    - Lista de materiales con semáforo de stock
    - Registro de consumo por orden de trabajo
    - Alertas de stock mínimo

  Módulo 6: TPM
    - Checklist de inspección diaria
    - Cálculo automático de OEE
    - Registro de incidentes
    - Panel de certificaciones

  Módulo 7: Reportes
    - Dashboard general con alertas
    - Exportación a Excel (openpyxl)
    - Reportes de mantenimiento, uso e inventario
